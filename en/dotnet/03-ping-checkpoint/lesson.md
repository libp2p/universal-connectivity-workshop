# Lesson 3: Ping Checkpoint

Learn to use the built-in Ping protocol to verify connectivity and measure round-trip time.

## Learning Objectives
- Understand the Ping protocol
- Use built-in libp2p protocols  
- Measure network latency

## Your Task
Use the Ping protocol (built into dotnet-libp2p) to ping a remote peer and measure RTT.

## Key Concepts
Ping in libp2p (/ipfs/ping/1.0.0) works like ICMP ping but over libp2p connections.

## Implementation
The Ping protocol is automatically available. After connecting to a peer, you can send ping requests.

## Success Criteria
- Connect to remote peer
- Exchange ping messages
- Measure and print RTT
