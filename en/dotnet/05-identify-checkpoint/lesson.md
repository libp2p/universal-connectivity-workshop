# Lesson 5: Identify Checkpoint

Use the Identify protocol to exchange peer metadata and discover capabilities.

## Learning Objectives
- Use Identify protocol for peer metadata exchange
- Understand protocol negotiation
- Discover remote peer capabilities

## Background
The Identify protocol (/ipfs/id/1.0.0) allows peers to exchange:
- Agent version
- Protocol version
- Supported protocols
- Listen addresses
- Observed addresses

## Your Task  
Connect to a remote peer and use Identify to discover its metadata.

## Success Criteria
- Connect to remote peer
- Exchange Identify information
- Print remote peer capabilities
