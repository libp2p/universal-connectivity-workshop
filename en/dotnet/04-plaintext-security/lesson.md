# Lesson 4: Plaintext Security

Learn about the security layer in libp2p by using the plaintext protocol (for educational purposes).

## Learning Objectives
- Understand security protocols in libp2p
- Configure plaintext (unencrypted) connections
- Learn when to use plaintext vs encrypted transports

## Background
libp2p supports multiple security protocols:
- **Noise**: Modern, recommended encryption
- **TLS**: Standard TLS 1.3
- **Plaintext**: No encryption (testing/learning only)

## Your Task
Configure your peer to use plaintext security for educational demonstration.

## Warning
⚠️ Plaintext provides NO encryption. Only use in trusted networks or for learning!

In production, always use Noise or TLS.

## Success Criteria
- Configure plaintext security
- Connect to remote peer
- Understand security layer trade-offs
